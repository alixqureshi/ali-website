Playbook 05 · 5 min read · Updated 20 Oct 2026

My tech stack. Every tool I use to run Adcrate and build with AI, what each one is for, and what I dropped.

People ask what we use. This is the list as of this month, with no affiliate links. The tools that run a performance creative agency shipping 500+ ads a week, and the rules I use to pick them.

01How I choose tools 02Where I work 03Which model does what 04Research and ad data 05Creative production 06Creator ops 07Running the business 08Hosting and infrastructure 09What I dropped, and why

01How I choose tools

Tools change every month. The rules don’t. These 5 decide almost everything on this page.

  • One source of truth per thing. Notion for work, Xero for money, the ad platforms for performance. Everything else reads from them live. Nothing keeps its own copy.
  • Everything needs a way in for AI. If a tool has no API or connector, an agent can’t use it. It stays a job for a person forever.
  • Cheapest engine that works. Plain code first, then a scheduled routine, then a script on a machine I own, then the paid API.
  • Self host when per seat pricing punishes you. If the whole team needs to see something, paying per seat makes no sense.
  • Prototype first, harden the survivors. Every new agent or tool starts as the scrappiest version that works. Only the ones we keep using get rebuilt properly.

Things I built

When a job kept coming back, we built a tool for it. Most are small MCP servers, so Claude uses them like any other connector:

  • An advertorial builder. Brand extraction, research, brief, copy validation, preview and publishing for pre-sell pages.
  • A carousel pipeline. Renders carousels from a brief.
  • A YouTube research tool. Transcripts and channel search, for finding what’s working.
  • A brain connector. Serves my skills and context to Claude and ChatGPT in the browser.
  • The agent runner and dashboard. Where our 94 agents report in, and where a person approves anything that goes out.

09What I dropped, and why

Front and MissiveLooked at both for creator comms. Per seat pricing, for a team that all needs to see everything. Chatwoot instead.
SendBlueTried it for iMessage. Only spam came through. Replaced with our own bridge on the Mac mini.
AirMoved our asset library to pics.io in August.
QuickBooksMoved to Xero, owned by our finance lead.
Group chats300+ WhatsApp groups with creators, there only so the team could see the chats. One shared inbox replaced them all.
Public Notion pagesWe used to share creator briefs as public pages. It nearly got our workspace switched off. Private links now.

Pick tools your agents can reach. Build your own only for the jobs that keep coming back.
